# 🚀 Things I've Built

## 🧭 PathPilot AI

**A personalized learning planner that turns a learning goal into a structured roadmap.**

Instead of giving learners another collection of links, the idea is to help answer:

> **“What should I learn next?”**

**Focus:** Personalized learning • Roadmap generation • Modern web UI

**Tech:** React ecosystem • Vite • TanStack Start • Vercel

---

## ⚙️ MachinePulse

**Predictive Machine Maintenance Dashboard**

A machine-monitoring application that uses machine parameters to predict whether equipment is likely to experience a failure.

The project combines an ML model with a dashboard so that predictions are presented as something a user can actually interpret rather than just a raw model output.

**Highlights**

* Random Forest classification
* Machine sensor feature analysis
* Failure-risk prediction
* Interactive dashboard
* Prediction visualization
* Flask backend
* React frontend

**Tech:** Python • Flask • scikit-learn • Pandas • React • Chart.js

---

## 🦷 Halo Dental Care

A responsive dental-care web application designed around a real-world clinic workflow.

The project focuses on making information easy to find and simplifying appointment interaction through a clean frontend experience.

**Tech:** React • JavaScript • HTML5 • CSS3

---

## 🏥 SmileHub Dental Care

A full-stack dental appointment platform designed to connect the patient-facing interface with backend services and database functionality.

**Tech:** React • Node.js • Express.js • MongoDB • JavaScript
